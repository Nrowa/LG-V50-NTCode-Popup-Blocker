# NT-Code Popup Blocker v1.0.0

## What's included

- LSPosed module for the specific LG NT-Code warning dialog in `com.android.phone`.
- Dialog title and message matching before suppression.
- First public release package built by GitHub Actions.

## Install

1. Download `NTCode-Popup-Blocker-v1.0.0-debug.apk` below.
2. Install it on the phone.
3. Enable the module in LSPosed and select **Call services** (`com.android.phone`) only.
4. Reboot.

## Notes

- This hides the warning dialog; it does not fix NT-Code, carrier configuration, firmware, or modem behavior.
- APK is a debug build and is not signed with a production release key.
- User-reported successful test: LG V50 ThinQ LM-V500VM running Android 12.
- Other device and software combinations are unverified.
