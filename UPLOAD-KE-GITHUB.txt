PANDUAN SINGKAT — BUILD APK OTOMATIS

1. Extract ZIP ini di komputer.
2. Buat repository baru di https://github.com/new (Private disarankan).
3. Upload ISI folder project ini ke ROOT repository. Setelah upload, root harus langsung berisi folder app/, folder .github/, build.gradle, settings.gradle, dan gradle.properties. Jangan sampai semuanya berada di dalam folder bertingkat NTCode-Popup-Blocker-GitHub-Actions/NTCode-Popup-Blocker-GitHub-Actions/.
4. Commit/upload ke branch main atau master. File .github/workflows/build-apk.yml akan menjalankan build otomatis setiap ada push ke branch tersebut.
5. Di GitHub, buka tab Actions, pilih workflow "Build NT-Code Popup Blocker APK", lalu buka run terbaru.
6. Jika status hijau/success, scroll ke bagian Artifacts dan download "NTCode-Popup-Blocker-debug-apk". Extract artifact ZIP itu untuk mendapat app-debug.apk.
7. Install APK di Android, aktifkan modul lewat LSPosed, pilih scope hanya com.android.phone / Call services, lalu reboot.

CATATAN PENTING
- Yang dibuild workflow ini adalah debug APK, bukan release APK.
- Workflow menjalankan compiler; keberhasilan build belum membuktikan hook cocok dengan implementasi popup pada firmware HP. Periksa LSPosed Logs setelah reboot.
- Modul hanya mencoba menyembunyikan dialog yang cocok dengan judul/pesan yang diamati. Ini tidak memperbaiki sumber masalah NT-Code.
- Kalau run gagal, buka tab build run yang merah dan kirim log error-nya untuk diperiksa.
- Jangan aktifkan scope System Framework. Untuk rollback, nonaktifkan modul di LSPosed lalu reboot.
